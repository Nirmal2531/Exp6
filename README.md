# Exp - 6 STUDENT ONLINE EXAM REGISTRATION SYSTEM

# AIM:
To study the problem statement and Software Requirement Specification (SRS) of an Online Examination Registration System and design the required UML diagrams for the system.
# SRS (Procedure):
Step 1: Problem Identification

The main problem is the need for a secure and automated system to manage online examination registration. Students should be able to register for examinations easily, while examiners and administrators manage examination details, registrations, and related activities efficiently.

Step 2: Requirement Analysis
Actors:
Student
Examiner
Admin
Functional Requirements:

Student:

Register for an examination
View examination details
Select available examinations
View registration status

Examiner:

Create examination details
View registered students
Manage examination information
Update examination schedules

Admin:

Manage student accounts
Manage examiner accounts
Approve and manage examination registrations
Maintain examination records
Step 3: System Design

The Online Examination Registration System consists of three main actors—Student, Examiner, and Admin. The system provides facilities for examination registration, examination management, user management, and maintaining registration records.
